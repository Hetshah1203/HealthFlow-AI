# HealthFlow-AI

## Overview

HealthFlow-AI is a reference implementation of a **machine‑learning powered health data processing pipeline**. It demonstrates how to ingest, clean, and analyze health‑related datasets using modern Python tools and exposes a simple web API for visualising predictions.

## Features

- **Data ingestion** – CSV/JSON loaders with validation using **pydantic**.
- **Pre‑processing** – Missing‑value handling, feature scaling, and categorical encoding.
- **Modeling** – Scikit‑learn pipelines with a configurable model (e.g., RandomForest, LogisticRegression).
- **API** – FastAPI server exposing endpoints to upload data, trigger training, and retrieve predictions.
- **Testing** – Basic unit tests using **pytest**.
- **Containerisation** – Dockerfile for easy deployment.

## Getting Started

### Prerequisites

- Python 3.9+ (recommended via `pyenv` or virtualenv)
- Git
- Optional: Docker (for containerised run)

### Installation

```bash
# Clone the repository (already done)
git clone https://github.com/Hetshah1203/HealthFlow-AI
cd HealthFlow-AI

# Create a virtual environment
python -m venv venv
source venv/Scripts/activate  # on Windows PowerShell

# Install dependencies
pip install -r requirements.txt
```

### Running the API locally

```bash
uvicorn src.app:app --reload
```

The API will be available at `http://127.0.0.1:8000`. Swagger UI can be accessed at `http://127.0.0.1:8000/docs`.

### Running tests

```bash
pytest
```

### Dockerised run (optional)

```bash
docker build -t healthflow-ai .
docker run -p 8000:8000 healthflow-ai
```
